These are per-task availability/completion values. The player’s numeric spatula inventory is saved separately and is not duplicated by this shift.

This is an event-order and memory-layout calculator, not a frame-perfect game simulation. “Unknown” means the selected object profile does not establish an exact value. A safe save requires every corrupted numTasks field to be either untouched at its original value or exactly zero.
