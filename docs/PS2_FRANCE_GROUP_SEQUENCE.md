# French group sequence

`france_group_sequence.generate_unit` independently proves all nine original
members of `xGroup.cpp` at `0x2a0070`, using the existing 200-byte item accessor
at `0x2a00d0`. The full span is 1,404 bytes, including zero alignment; function
code totals 1,352 bytes. Eight new identities contribute 1,152 bytes.

Each of the three authenticated debug originals provides the complete membership,
linkage names, extents, matching instruction operands and sequence placement.
The existing accessor/count context verifier independently replays Germany,
whose prior accessor registry had only USA/PAL provenance. All intervening
alignment must remain zero and the complete normalized sequence must have one
location in France. New records require all three independent witnesses.

Six new members pass the existing strict local return/stack verifier. Load and
save are the original eight-byte J/NOP wrappers, whose exact destinations are the
already independently identified `xBaseLoad` and `xBaseSave`. A scoped wrapper
check requires unchanged SP/RA and a strict complete return body at those known
callees. It does not relax the general boundary verifier. Initialization's sole
changed address pair must point to the local event callback, at the original
HI/LO offsets and with the original opcode. No data identity is added.

External transfers use existing named identities, including the independently
reviewed nonprogress allocator. This proof checks the complete 32-byte event
wrapper as nonpromoted context in all three originals. The separate event
sequence proof then establishes that wrapper and its larger implementation,
rooted in this independently regenerated group caller. Group regeneration
explicitly excludes the dependent event records from its known anchors, so
registration cannot introduce circular evidence.

The complete source object reports nine exact functions / 1,352 bytes,
up from the existing 200-byte accessor. Its profile includes verified external
calls, the local callback address pair and the independently reviewed
`gActiveHeap` operand. With the event sequence integrated, all five callback
calls are restored. Independent original-byte reconstruction verifies the
712-byte callback together with all 880 event bytes; see
`PS2_FRANCE_EVENT_SEQUENCE.md`. No compiler or scoring settings change, and
these function comparisons do not establish a linked executable.

Private artifacts in the PS2 worktree are `build/group-france-proof.json`,
`build/group-france-diagnostic/target.o` and `relocations.json`, the retained
whole source object, and `build/group-proof-negative-controls.json`. Negative
controls reject altered item displacement, a load tail redirected to save, a
changed callback address, and altered event-wrapper arithmetic. Python syntax
validation also passes.
