# French core source comparisons

Four additional France-only profiles compile the complete existing xQuickCull,
xSurface, xCounter and xutil sources against every independently verified member
of each unit. No original boundary, identity, denominator or completion status
changes. Missing source routines remain unmatched targets.

Canonical overload names are taken from authenticated DWARF references recorded
in the existing corroboration registries. All three references agree. Thirteen
quick-cull calls, one counter call and one utility call use already confirmed
French destinations with the existing inverse relocation checks. An unresolved
allocator call is left unnamed.

The actual production report increases from 3,900 to 5,952 code-matched bytes:
quick-cull contributes 1,916, the surface getter 40, and the counter reset 96.
The utility subset initially adds comparison coverage only. All other unit
results are unchanged apart from insignificant floating-point aggregation
rounding. The debug-region effective profiles are unchanged, since these four
entries accept only the authenticated French executable hash.

The standard objdiff code metric is preserved; this is not a complete retail
link claim. Private reproducible evidence is in build/france158, including the
original-reference checks, compiled objects, production report and validation.
